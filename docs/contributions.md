# Contributions and team responsibilities

## My contribution

I primarily worked on the programming aspect of Dome Guard. The project programming concept involved an ESP32-based controller intended to process environmental sensor readings and control the servo-driven folding mechanism.

The original source code is no longer available to me. This repository does not claim to contain or reproduce the original firmware.

## Team contributions

- Teammates handled circuit connections and electronic hardware integration.
- Teammates worked on physical prototype construction.
- The team conducted research and prepared project documentation.
- The team completed the prototype and presented the project at college.

Dome Guard was a collaborative group project. This file distinguishes my programming contribution from the hardware tasks handled by teammates.
