# Project overview

## Dome Guard — Automated Foldable Dome System for Plants

Dome Guard was a 2025 academic group micro-project at Kottayam Institute of Technology & Science, affiliated with APJ Abdul Kalam Technological University.

The project explored an automated foldable protective dome intended to help protect plants from changing weather conditions. The design combines environmental sensing, an ESP32 microcontroller and servo-driven mechanical movement.

## Motivation

Plants in small gardens and cultivation spaces can be exposed to rainfall, temperature changes and wind. Manual covering can require repeated human intervention. The project explored whether sensor-based control and a foldable cover could automate part of this task.

## Main idea

Environmental sensors provide information to an ESP32. The controller is intended to evaluate the readings and command servo motors to move the dome.

## Intended applications

The project report discusses possible use in home gardens, terrace gardens, urban gardening and small-scale cultivation. These are intended application areas, not evidence of commercial deployment.

## Project record

The team completed a physical prototype and presented it at college. The original firmware and physical prototype are no longer available to the repository maintainer. This repository preserves the project description, architecture and available diagrams.
