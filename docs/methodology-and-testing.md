# Methodology and testing approach

## Development approach described in the project materials

The project report describes a development process involving:

1. **Design and planning:** Select the controller, sensors, servo motors and mechanical arrangement; prepare the system architecture.
2. **Prototype development:** Assemble the dome structure, connect sensors and actuators, and develop the controller program.
3. **Testing and calibration:** Consider sensor response, servo movement and operation under different environmental conditions.
4. **Final adjustments and documentation:** Refine the design and document the project.

## Testing areas proposed in the report

- Rain sensor response to water droplets and rainfall.
- DHT22 temperature and humidity readings.
- Servo actuation accuracy, speed and load handling.
- Repeated opening and closing cycles.
- System operation under changing environmental conditions.

## Evidence boundary

The available report describes a testing plan and proposed evaluation activities. It does not provide a complete verified dataset in the materials used to create this repository. The testing items above are therefore documented as proposed evaluation areas, not measured results.

The team did complete a physical prototype and presented it at college.
